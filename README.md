A continuación presento una solución completa, profesional y ejecutable para construir una API REST en Visual Studio 2022, 
conectada a Oracle Database 19c, incluyendo registro y consulta de información, y procedimiento detallado para pruebas con Postman.

* La solución está alineada con prácticas empresariales y académicas.

## 1. Arquitectura de la solucion:
* Tecnologías utilizadas
* Visual Studio 2022
* .NET 8 (ASP.NET Core Web API)
* Oracle Database 19c
* Oracle Managed Data Access (ODP.NET)
* Postman

## 2. Creacion del proyecto en Visual Studio 2022:
* Abrir Visual Studio 2022
* Create a new project
* Seleccionar ASP.NET Core Web API

* Configurar:
* Project name: OracleApiDemo
* Framework: .NET 8
* Authentication: None
* Enable HTTPS: Yes
* Use controllers: Yes
* Finalizar.

## 3. Instalación de paquetes NuGet:
* Abrir Package Manager Console y ejecutar:
* Install-Package Oracle.ManagedDataAccess.Core

## 4. Creación de la tabla en Oracle 19c:
Ejecutar en Oracle SQL Developer:
```
CREATE TABLE USERS_API (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NAME VARCHAR2(100) NOT NULL,
    EMAIL VARCHAR2(100) NOT NULL,
    CREATED_AT DATE DEFAULT SYSDATE
);
```

## 7. Servicio de acceso a datos (Repository):
Crear carpeta Data
Archivo OracleRepository.cs:
```
using Oracle.ManagedDataAccess.Client;
using OracleApiDemo.Models;
using System.Data;

namespace OracleApiDemo.Data
{
    public class OracleRepository
    {
        private readonly IConfiguration _configuration;

        public OracleRepository(IConfiguration configuration)
        {
            _configuration = configuration;
        }

        private OracleConnection GetConnection()
        {
            return new OracleConnection(
                _configuration.GetConnectionString("OracleConnection")
            );
        }

        public void InsertUser(UserModel user)
        {
            using var conn = GetConnection();
            conn.Open();

            using var cmd = new OracleCommand(
                "INSERT INTO USERS_API (NAME, EMAIL) VALUES (:name, :email)", conn);

            cmd.Parameters.Add(new OracleParameter("name", user.Name));
            cmd.Parameters.Add(new OracleParameter("email", user.Email));

            cmd.ExecuteNonQuery();
        }

        public List<UserModel> GetUsers()
        {
            var users = new List<UserModel>();

            using var conn = GetConnection();
            conn.Open();

            using var cmd = new OracleCommand(
                "SELECT ID, NAME, EMAIL FROM USERS_API", conn);

            using var reader = cmd.ExecuteReader();

            while (reader.Read())
            {
                users.Add(new UserModel
                {
                    Id = reader.GetInt32(0),
                    Name = reader.GetString(1),
                    Email = reader.GetString(2)
                });
            }

            return users;
        }
    }
}
```
## 8. Configuración de inyección de dependencias:

Editar Program.cs:
```
using OracleApiDemo.Data;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllers();
builder.Services.AddScoped<OracleRepository>();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();
```
## 9. Controlador REST:

Crear carpeta Controllers
Archivo UsersController.cs:
```
using Microsoft.AspNetCore.Mvc;
using OracleApiDemo.Data;
using OracleApiDemo.Models;

namespace OracleApiDemo.Controllers
{
    [ApiController]
    [Route("api/users")]
    public class UsersController : ControllerBase
    {
        private readonly OracleRepository _repository;

        public UsersController(OracleRepository repository)
        {
            _repository = repository;
        }

        [HttpPost]
        public IActionResult CreateUser([FromBody] UserModel user)
        {
            _repository.InsertUser(user);
            return Ok(new { message = "Usuario registrado correctamente" });
        }

        [HttpGet]
        public IActionResult GetUsers()
        {
            var users = _repository.GetUsers();
            return Ok(users);
        }
    }
}
```

## 11. Pruebas con Postman:
* 11.1 Registro de usuario (POST)
* URL
* POST https://localhost:7xxx/api/users

* Headers
* Content-Type: application/json
* Body (raw / JSON)
```
{
  "name": "Juan Perez",
  "email": "juan.perez@email.com"
}
```
* Respuesta esperada
```
{
  "message": "Usuario registrado correctamente"
}
```
* 11.2 Consulta de usuarios (GET):
* URL
* GET https://localhost:7xxx/api/users

* Respuesta esperada
```
[
  {
    "id": 1,
    "name": "Juan Perez",
    "email": "juan.perez@email.com"
  }
]
```
